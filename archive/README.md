# Archive: Pre-Elm Legacy Display Artifacts

This directory preserves the historical display artifacts and templates that were superseded by the **Elm 0.19.3** frontend rewrite (`elm/`).

## Contents

### 1. `legacy_html/`
Pre-Elm static HTML observatories originally generated by Python string interpolation (`build_dashboard.py`):
- `show-me-hn-50471731.html` (Microsoft 365 outage, 762 comments)
- `show-me-hn-50472038.html` (Rust 1.100 release, 254 comments)
- `show-me-hn-50500963.html` (Live HN capture)

*Note: The canonical benchmark artifact `show-me-hn-50467087.html` lives at the repository root and is powered by the Elm display layer (`elm/dist/observatory.js`).*

### 2. `legacy_display/`
- `build_dashboard_legacy.py`: The original monolithic ~2,000-line Python dashboard compiler that inlined HTML DOM trees, SVG charts, and ~530 lines of client-side vanilla JavaScript into a single HTML file before the display layer was extracted into Elm.

## Migration Context

In pull request #1 (`elm-display-layer`), the display layer was rewritten in Elm 0.19.3 with:
- The Elm Architecture (Model / Update / View)
- Strict type safety and decoders (`elm/src/Observatory/Decode.elm`)
- Pure `rgb()` / `rgba()` zero-hash invariant across all markup and styling
- Automated visual and DOM parity differ (`elm/scripts/diff-parity.js`)
